# Smart Wheelchair with Multi-Control Navigation and Safety Monitoring

## 📌 Project Overview

The Smart Wheelchair is an intelligent assistive mobility system designed to improve the independence and safety of individuals with physical disabilities.

The system is based on the ESP32 DevKit V1 microcontroller and provides multiple control methods for operating the wheelchair.

## 🚀 Key Features

### Multi-Mode Control

The wheelchair provides multiple methods of operation:

- 📱 Mobile App Control
- 🎤 Voice Control
- ✋ Hand-Gesture Control
- 🕹️ Physical Joystick Control

### Safety Monitoring

- MPU6050 sensor for fall and tilt detection
- Emergency monitoring
- Impact detection
- Safety alerts

## 🛠️ Hardware

- ESP32 DevKit V1
- MPU6050
- Joystick
- Ultrasonic sensors
- Motors
- Motor driver
- Bluetooth / Mobile application

## 💻 Technologies

- Embedded Systems
- ESP32
- IoT
- Sensors
- Bluetooth
- Mobile App Control
- Embedded C/C++

## 🎯 Objective

To develop a cost-effective smart mobility solution that provides multiple control methods and improves safety for users with physical disabilities.
